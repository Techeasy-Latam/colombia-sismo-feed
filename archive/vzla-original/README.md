# Archivo — proyecto original (Venezuela)

Este repositorio nació como un fork/adaptación de `vzla-sismo-feed`, un feed de emergencia construido para el doblete sísmico del 24 de junio de 2026 en Venezuela. Estos archivos son remanentes de ese proyecto original: no forman parte del build de la app (Next.js no los toca) y su contenido (cifras, fuentes, branding) corresponde al evento de Venezuela, no al sismo de Chocó, Colombia, que cubre este repositorio hoy.

Se movieron acá en vez de borrarse para no perder el historial de diseño y contenido del proyecto original.

## Contenido

- `outputs/` — mockups HTML estáticos de exploración de diseño (`glass-mockup*.html`, `mockup-rediseno.html`, `paleta-y-navbar-v3.html`, `mockup-preview/`), con branding "Sismo Venezuela" y datos de ejemplo hardcodeados.
- `guion-video-sismo-venezuela.md` — guion de un video de difusión del proyecto original.
- `repomix-output.xml` — snapshot empaquetado del código del proyecto original en un punto anterior en el tiempo (generado con [repomix](https://github.com/yamadashy/repomix)); desactualizado respecto al código actual.
